# Project submission

## Title

Recipely: Java Web Recipe Sharing Platform

## Description

Recipely is a role-based Java web application for sharing, discovering and moderating recipes. The project uses Jakarta Servlets and JSP for the web layer, JDBC with SQLite for persistent storage, and object-oriented Java design for role permissions, recipes and moderation. It also demonstrates generic repositories, collections, custom exceptions, session authentication, and a synchronized scheduled metrics cache. The expected result is a locally runnable recipe platform where contributors submit recipes, administrators moderate them, and visitors discover approved recipes using filters.
